# 🐍 Finanzas con Python

Este repositorio reúne distintos proyectos y notebooks creados por Farid Ríos, enfocados en el mundo de finanzas y análisis de datos con distintas herramientas de programación. 

La idea es tener un espacio organizado donde guardo código útil, práctico y reutilizable, que me sirve tanto para aprender como para aplicar en proyectos reales.

---

## 📁 Contenido

El repositorio está dividido en carpetas temáticas, cada una con scripts y notebooks listos para usar:

- [Calculadoras](./calculadoras) → herramientas para rendimientos, tasas, conversiones, etc.
- [Análisis](./analisis) → notebooks con exploración de datos y métricas financieras. 
- [Proyecciones](./proyecciones) → modelos simples de estimación como Run Rate, Forecasts y más.
- [Otros](./otros) → utilidades y funciones que complementan el trabajo con datos financieros.

---

## 🎯 Objetivo 
- Consolidar en un solo lugar proyectos de finanzas aplicadas, orientados al análisis cuantitativo y modelado financiero.
- Demostrar lo que voy aprendiendo y cómo lo pongo en práctica. 
- Compartir código que pueda ser replicado, adaptado y mejorado por otros.
